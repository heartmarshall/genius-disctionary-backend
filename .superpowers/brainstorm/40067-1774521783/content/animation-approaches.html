Анимация карточки: 3 подхода

Кликни на демо-область, чтобы увидеть вход → выход → вход. Выбери понравившийся вариант.

Approach A

Elastic Spring

Карточка "пружинит" по вертикали — сжата, распрямляется с лёгким перелётом, при закрытии быстро сжимается обратно.

Approach B

Smooth Unfold

Карточка "разворачивается" от строки слова — clip-path расширяется из точки, создавая эффект раскрытия бумаги.

Approach C

Scale + Blur Morph

Карточка "материализуется" с размытием — из blur + scale в чёткое состояние, как фокусировка камеры.
